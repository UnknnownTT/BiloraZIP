# Security policy

BiloraZIP handles untrusted archive data. Please do not publish an exploit or a malicious archive before maintainers have an opportunity to investigate.

For now, report a security issue privately to the repository owner using a private GitHub security advisory once a public repository is available. Do not include passwords, personal files or private data in a public issue.

Supported candidate: 1.0.0 RC1 (Windows x64). Experimental BILZ-1 is not considered production-grade. The repository does not promise a formal response SLA.
